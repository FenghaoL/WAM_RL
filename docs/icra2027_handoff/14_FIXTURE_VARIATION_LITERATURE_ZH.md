# 插入研究的底座变化：证据与本文定位

核查日期：2026-09-16。本文件补充第13份说明，不修改论文。范围数值必须区分底座的世界位置、插头相对孔位的初始误差、目标位姿观测噪声；三者不可直接排名。

## 结论

确实有固定插座的模仿学习研究，也有移动插座的监督学习和强化学习研究。固定目标允许利用绝对位置捷径，但仅凭固定不能证明策略过拟合；更准确的评价是该实验没有检验目标位置变化下的泛化。即使目标固定，抓持误差、姿态、接触和滑移仍可能需要反馈控制。强化学习同样可能学到固定位置捷径。

本文底座沿两个桌面轴约±1 cm（2×2 cm区域）、待插物约±2 cm（4×4 cm区域），训练和测试处于相同近似范围。它是有实际意义的局部目标位置变化，增加了固定底座协议未考察的变化维度，但不属于大范围或域外位置泛化，也没有证据支持在文献中排名。位置由作者近似描述，不假设独立或均匀采样。

## 本文的变化是什么水平

1. **相对固定孔的IL协议**：多考察了目标位置变化，而非仅待插物或手臂起点变化。可以如实呈现这个设置，不应称其他方法过拟合。
2. **相对装配文献整体**：属于小范围局部平移变化。已有研究覆盖更广随机化、新目标位姿和动态插座，因此移动底座本身不构成新方法贡献。
3. **相对本文技术路线**：低成本机器人上的视觉WAM，需要在抓取后根据观测完成局部对准与纠正，这个设置是有用的评估条件。它不能由厘米数推导为优于显式定位或力控方法。
4. **相对泛化主张**：训练测试同范围，支持域内位置变化评估；不能称未见空间分布泛化。未记录逐次坐标与边缘覆盖，也不能说区域内任意位置都可靠。

要判断±1 cm是否造成实质对准难度，还需要孔与插入物的实际间隙、倒角捕获范围、姿态变化、抓持误差和接近位置。初始化移动1 cm不等于插入时仍有1 cm误差；视觉策略可能在接近时已经消除大部分偏差。

## 若要排查“记住一个位置”，最直接的补充实验

固定待插物起点，保持抓取与相机设置一致，仅改变底座：中心、左1 cm、右1 cm、前1 cm、后1 cm，共5个位置。测试同一个SFT和同一个纠正后模型，每位置3次可做初筛，5次则每模型25次；随机交错顺序以减少机械状态与时间漂移影响。明确这是新实验，不混入已有成功率。

记录每次实际底座位置、成功、首次接近/接触位置与是否纠正。若机械臂接近位置随底座改变，说明它对目标变化有响应；若一律去同一位置然后进行搜索，仍可能完成任务，但机制不同。若始终去同一位置且移开即失败，则支持位置捷径疑虑。仅看最终成功率无法区分视觉对准与接触搜索。

这是目标位置响应诊断，不是新恢复半径基准。需要测试外推时，再单独加入训练范围外的±2 cm底座位置；不得把待插物训练范围±2 cm误当作底座训练也覆盖±2 cm。

## 推荐论文表述

> We evaluate full-task execution under local placement variation of both the manipulated object and the receiving fixture, rather than a single fixed fixture location. Training and evaluation share the same approximate placement envelope.

该句属于协议说明，不是与外部论文的性能比较。主线仍然是人类纠正与保留时间上下文的WAM后训练，以及预测质量和行为收益之间的任务依赖关系。
