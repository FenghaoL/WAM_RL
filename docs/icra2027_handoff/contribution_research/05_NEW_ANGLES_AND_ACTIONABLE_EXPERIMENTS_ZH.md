# 更贴近WAM纠正学习的研究切入点与实验清单

## 1. 最推荐的主问题

**短人类纠正能否让预测式机器人策略获得“从错误状态继续推进”的能力；哪些训练条件决定这种能力能否被学到？**

比“WAM在精密操作中比VLA强”更可验证的主张是：WAM有可被交互视频监督的预测分支，但这一潜力只有在短接管的上下文和目标范围被合理处理时才可能转化为恢复能力。当前结果支持完整纠正配方有初步收益，还没有隔离出WAM架构优势。

建议形成三项连贯贡献：

1. 针对短接管，区分历史条件、专家动作与未来视觉目标的WAM后训练协议。
2. 通过同数据对照与监督覆盖审计，解释哪些信息被片段裁剪丢失，哪些设计实际影响学习。
3. 在完整任务、共享偏差起点和第二任务上评价恢复能力，区分“更少犯错”“纠错后完成”与“仅动作更活跃”。

第三项不必是新模型。贡献强度取决于可复现发现，而非是否列满三个算法模块。下面的提案按现有资源和1–2天内价值排序；未实现项不列入正式算法。

## 2. 新检索的近邻带来的约束

| 一手工作 | 可借鉴的实验思想 | 本项目不能照搬的主张 |
|---|---|---|
| [STAIR](https://arxiv.org/html/2606.15587v1) | 区分对准帧重采样与新增恢复状态覆盖，并学习局部动态特征 | “精细对准片段短”“视频动态帮助动作”本身已有近邻 |
| [FACT](https://arxiv.org/html/2608.10232v1) | 失败数据监督视觉后果而非动作模仿，单独验证预测质量与动作结果 | 当前AHA配置无动作条件世界模拟器/价值头，不能声称复现其因果后果学习 |
| [EgoRecovery](https://arxiv.org/html/2607.19745v1) | 区分正常起点与失败起点成功率，并做恢复数据预算对照 | 当前没有人类ego视频到机器人意图迁移模块，不应借其能力作为已有贡献 |
| [CoRe](https://arxiv.org/html/2608.14822v1) | 从扰动类型与发生阶段组织配对恢复测试 | 当前没有模型内反事实恢复或外部状态重建 |
| [π*0.6 / RECAP](https://arxiv.org/html/2511.14759v1) | VLA也能从部署纠正和经验中改善，关注完成与吞吐 | 当前监督纠正不是优势条件化RL，不能以“VLA不能从错误学习”为前提 |
| [MEM](https://www.pi.website/research/memory) | VLA也能具有短期视觉和长期记忆 | “VLA单帧、WAM有记忆”不是可靠分类，更不是公平对照 |

这些文献中多项为2026年预印本；可作为近邻和设计依据，不把其所有方法与数字当作成熟标准。下面的实验是针对本仓库提出的方案，性能未知。

## 3. 提案A：区分“避免错误”与“从错误恢复”——首选，零训练

**假设。** 纠正训练的收益不只是把一条正常轨迹拟合得更精确，而是扩大了偏差状态下继续完成的范围。

**实验。** 第一部分盲标现有全部SFT/full/vidext录像，分抓取与插入阶段记录初次失准、定向调整、阶段完成和最终成功。第二部分用同一组人工预置偏差起点测试SFT与一个纠正模型，采用9种平面偏移×3重复×2模型＝54次短测试。详细操作见[评估协议§5–6](04_EVALUATION_SIZE_AND_RECOVERY_PROTOCOL_ZH.md)。先做cylinder插入，再用power少量相同结构条件验证可迁移性。

**固定项。** 同checkpoint、history reset、求解步数、夹持姿态、超时和目标位置；所有模型从相同准备流程开始。人为局部起点与自然完整任务单独统计。

**图表。** 一张阶段结果图、一张方向/幅度恢复图、两段带相同标注规则的代表性纠偏视频。若有可测图像平面误差，再画误差随真实时间或决策步数下降的曲线。

**价值与边界。** 这是当前“明显纠错”最直接的量化升级。自然错误条件分布不同，不能仅靠条件恢复率说新模型在同错误上更强；共享起点解决这一问题。若只减少犯错而未增加局部恢复，论文改成精密执行可靠性提升，不强行讲恢复机制。预计主要是半天录像标注与一批短试验，不占三卡训练。

## 4. 提案B：纠正发生前的历史，是否决定能否学到恢复——首选，复用已排队实验

**假设。** 相同HUMAN动作在冷启动片段和真实接近历史下对应不同训练条件，保持历史有助于后训练与部署条件一致。

**实验。** 比较cylinder基本full与 `full_context_truncated`，SFT起点、HIL-v2、视频范围、1:1、3285步、global12、lr1e-5均固定。两者推理history6，完整任务与局部恢复协议分别保持一致。当前仓库已为该控制准备队列，不应重复训练同一配方。

**额外低成本分析。** 在固定验证集按段内可获得历史数分组（0帧与非0帧），同时报告同起点在跨界构造下的实际历史长度、有效视频mask、动作误差。分组阈值在看结果前固定；同一轨迹多个窗口是相关样本，汇总到轨迹或用轨迹簇处理。离线改善只解释学习诊断，不直接替代真机成功。

**更细的测试。** 对相同持物插入起点，统一先执行一段真实接近路径再开始评估；各模型使用同样的历史构造。在另一个独立协议中全部清空缓存测试冷启动。训练方法×测试上下文形成2×2，区分后训练改进与单纯部署依赖记忆。两种物理流程若不同，不能直接把差异归因于缓存；应尽可能保持同一实际前缀，只改变是否向模型保留它。

**结论范围。** 若跨界训练优势主要在保留真实历史时出现，可提出“恢复后训练需要状态条件一致性”的实证发现。若无差异，不把记忆处理升为性能贡献；也不能从AHA一项实验推及所有WAM。

**仓库现状。** [power v3说明](../../ovcr_rl_token/padapter_hil_v3/README_ZH.md)和[cylinder队列说明](../../ovcr_rl_token/cylinder_experiments/10_FULL_VARIANTS_ZH.md)已记录新增划分与队列；这是文档/配置状态，不是本轮确认训练完成。power `_segdemo`是段内历史构造整体对照，需核对实际配置；不能只按实验简称认定单一mask变化。

## 5. 提案C：WAM的视觉预测到底有没有帮助恢复——最值得新增的一次训练

**假设。** 在同样的人类动作监督下，真实交互视频的预测目标能使共享视觉表征更适合偏差恢复。

**最小对照。** 从同cylinder SFT出发，复制vidext配方，仅将video loss系数从1改0；保留HIL、未来读取配置、历史、动作mask、采样、步数、学习率和全量更新范围。不能拿旧OVCR adapter替代此对照。video-loss-off仍是带WAM预训练先验的模型，不是“无视频预训练模型”，也不是VLA。

**测试。** 与vidext同一批20–30个完整试验，以及提案A的一组局部偏差条件。对固定HUMAN验证集按相同noise/timestep比较动作损失，可辅助监测，但不能以总loss比较有/无辅助项。

**可支持什么。** 成功率或恢复范围稳定改善，支持“后训练视觉目标提供额外价值”。如果两者接近，当前收益可能主要来自人类动作、数据覆盖或历史条件；不要把自监督作为主因。

**若有第二次训练预算。** 在video loss=0下进一步冻结Video DiT，保持动作分支与原生路由等其余更新范围一致；这隔离视觉参数可塑性。现有FullTrainer拒绝freeze_video_dit，需要新增训练范围并验证，不能仅改YAML。冻结后训练参数量变化是实验因素本身；报告参数和计算成本。

**为何强于另一个配比。** 它直接检验“WAM可利用纠正之外的视觉学习信号”这一核心解释。同1:1/2:1相比，额外训练更容易形成完整方法论证。但若三卡队列已无法腾出一夜，只完成A/B，不强行中断已授权的第二任务。

## 6. 提案D：WAM比VLA更容易从纠正中学习吗——有价值，但需要完整2×2

**不能预设答案。** 记忆、视频目标和模型规模并不严格按WAM/VLA二分。VLA也可以通过纠正学习恢复，且具备视觉记忆。因此把“WAM有优势”写成待验证问题。

最低比较矩阵：

| | 仅demo任务SFT | 相同demo+HUMAN纠正 |
|---|---|---|
| AHA-WAM | 已有 | 已有 |
| 一个实际可部署VLA | 需要对应任务SFT | 从该SFT继续训练 |

**最重要的条件。** 同一批demo/HIL与切分、同样两路相机和动作定义、相同任务/初始分布。各模型使用合理的原生归一化与优化器设置，不强行同学习率；但记录每来源样本暴露数、训练参数、更新数和墙钟。VLA与WAM预训练不同，因此是实例级比较，不能完全归因于架构。

**部署公平性。** 同控制频率与可比执行chunk长度，分别测原生延迟；若延迟差很大，再做匹配反馈延迟对照，不能一方冻结等待、一方异步执行却称纯模型能力比较。强制降低某模型的合理配置也不是公平。

**主指标。** 同时报告各模型SFT基线、纠正后成功率、局部恢复成功率和改进量：

$$
\Delta_{\mathrm W}=SR_{\mathrm W,H}-SR_{\mathrm W,SFT},\qquad
\Delta_{\mathrm V}=SR_{\mathrm V,H}-SR_{\mathrm V,SFT}.
$$

对 $\Delta_{\mathrm W}-\Delta_{\mathrm V}$ 的解释要考虑起点难度、天花板/地板效应与不确定性。不能仅因WAM从8%升46%、另一模型原本80%而增幅小，就说WAM更适合纠正。共享局部困难状态可减少这种混淆。

**可执行规模。** 选一个cylinder任务先做四模型×20共同布局＝80次完整试验；局部恢复另外测试。若已有正常部署的VLA SFT，仅需一个后训练；若完全没有，至少要新接数据、SFT、纠正和部署验证，1–2天通常风险很高。当前未在本仓库确认一套已经实测可用的VLA任务权重，不能假定已有。

**决策。** 有现成VLA才升为本次优先项，否则作为后续强扩展。省略VLA实测时题目不要写“WAM优于VLA”，用提案C验证同骨干的预测监督更干净。

## 7. 提案E：恢复能力来自“更多权重”还是“新的纠正状态覆盖”

**假设。** 原demo中缺少的偏差方向，不能靠同一批成功帧多训练几遍补出来；HIL的价值是提供恢复状态而非只延长训练。

**最低成本分析。** 标注原demo和HIL中的抓取/插入对准段，统计相对目标的可见偏差方向、是否发生回撤再对准、该阶段人工有效时长。按轨迹汇总，不把视频帧当独立数据。对无法可靠测量的三维误差只用可复核类别，不编造毫米精度。

**一次训练的强控制。** 从原SFT出发，将原demo中对准阶段提高采样概率，使对准起点抽样量接近HIL混合配方；全局12、3285步、lr1e-5，history与视频规则沿原demo。与原SFT和HIL纠正模型比较共享偏差起点。阶段标注预算、不同有效动作/视频监督量必须报告。这是同优化预算下的数据来源对照，不是完全等人工成本。

**更简单的控制。** 原demo-only再训练同样步数，排除单纯额外更新的解释，工程成本更低但不能隔离“对准帧权重”。已有原始demo四epoch权重不能替代继续训练控制。

**文献边界。** STAIR已研究重采样与新增恢复覆盖，因此不能把这个数据发现本身称为首次。WAM联动在于：新增状态在短接管中出现时，需要历史条件与视频mask相应处理；把E与B/C联合才有更具体的故事。

## 8. 提案F：少量纠正是否足够——数据效率，而不是训练步数曲线

**实验。** 在冻结HIL训练轨迹中按场景/阶段分层，固定seed取嵌套25%、50%、100%的完整rollout子集；所有模型从同SFT独立开始，demo与验证固定。每个子集保持1:1、3285步，使总优化预算一致，明确小子集被重复得更多。采用整条rollout，不能抽零散帧再让同轨迹视频进入另一个“未见”集合。

100%已有权重时，只做50%可形成一个预算对照；两点不能声称完整scaling law。若做25/50/100则至少两次新训练。相同HUMAN帧数与相同人工监控/重置时间并不等价，应同时报告人工标注有效时长、总交互时间和独立轨迹数。

**测试。** 固定完整任务与局部偏差条件，按训练子集包含/未包含的偏差方向分别观察泛化；开发前固定划分，不能事后挑最有利方向。把已有step1095/2190/3285画成曲线只能叫优化进度，不叫纠正数据效率，因为通常始终使用全部数据池。

**优先级。** 后续很有价值，但今天排在机制对照之后。IWR、EgoRecovery已有纠正数据预算研究，差异应落在WAM监督可用性和恢复收益之间的关系。

## 9. 提案G：视觉预测改善和动作恢复是否一致——现有权重可做的WAM诊断

**问题。** vidext提供更多视频目标，是否确实改善困难状态下的视觉预测；这种变化是否与动作改善一致？这是WAM特有的分析接口，比只画训练loss更有信息。

**实验。** 从独立验证rollout中固定一批抓取偏差、插入偏差及正常状态，按rollout划分，保留真实过去及未来。对SFT、基本full、vidext用相同输入/采样noise生成未来或计算固定视频flow验证损失，同时计算动作指标。先小规模10–20条不同rollout/片段试做，不以相邻窗口冒充独立样本。当前HUMAN验证很小，样本不足时直接报告不足，不能从训练集补成“泛化验证”。

可用视频flow loss/图像指标加明确任务事件：是否仍持物、是否接近孔、是否预测了实际未发生的成功。只做PSNR可能偏好模糊画面；人工事件判定需隐藏模型名。生成视频的历史/图像预处理和推理接口必须与训练定义对应，不能把preview里的另一个模式直接当等价世界模拟器。

**关键边界。** 当前 `action_conditioned=false`，预测不以实际后续动作串为条件；实际未来由人机混合控制决定，单一未来偏差不一定是“模型不懂物理”，也不能将生成的成功画面当可靠价值。该分析说明预测与策略表现是否共同变化，不证明二者因果关系。

**近邻与后续。** FACT直接研究动作条件下的失败后果，本项目若进一步加入失败视频，需要考虑当前无动作条件接口会混合不同控制后果。今天不建议把全部失败视频直接加进训练并称为新因果方法；优先作为可证伪诊断。结果若显示视频更好而动作无改善，也是有价值的边界。

## 10. 提案H：纠正后能否保留原技能——用现有2:1做有解释力的分析

**实验。** SFT、1:1基本full、2:1基本full，在同样正常起点和同样局部偏差起点分别测。前者看抓取与完整任务，后者看恢复；先各取相同20–30次预算而非只测试新方法困难情况。2:1没有vidext，应与无延伸1:1比较。

**图。** 横轴正常任务成功率，纵轴局部恢复成功率，每个配方一个点并带样本数。展示正常技能保留和恢复学习是否存在权衡，不把三个点称为完整Pareto前沿。若2:1两者均好，是本设置的配方结果，不是普适最优比例。

**优势。** 已有训练或队列可复用，新增负担主要在实机评估，适合截止前。它补充方法分析，但单独不足以作为新算法贡献。

## 11. 延迟实验放在什么位置

延迟实验的完整操作见[评估协议§7](04_EVALUATION_SIZE_AND_RECOVERY_PROTOCOL_ZH.md)。它能解释“纠正策略如何依赖反馈”，但不是精密恢复的第一证据。只有已有主结果、恢复图及核心机制对照后，再做模型×时延2×2。先不加入新加速算法，就能避免整篇论文叙事割裂。

若慢反馈让两个模型都失败，说明当前纠正能力受系统时序限制；若纠正模型在更大延迟下仍能完成，可报告限定条件的时延鲁棒性。不要将其与关节精度漂移或跨机械臂泛化混同。

## 12. 今天明天的组合建议

| 组合 | 内容 | 资源与定位 |
|---|---|---|
| 最稳妥 | 两任务SFT/纠正主表 + A恢复图 + B已排队历史对照 + H配比分析 | 优先机器人时间；复用现成训练，不额外搭新骨干 |
| 最贴近“WAM自监督” | 上述核心主表 + B + C video-loss-off + G预测诊断 | 需要一夜新增训练；可以回答视觉目标是否真的有用 |
| 最有跨范式比较价值 | A + D完整WAM/VLA 2×2 + 机制控制C | 只有已有VLA基础设施才可能在1–2天内可靠完成 |
| 后续扩展 | E覆盖控制 + F数据效率 + 多seed/跨session + 动作条件失败建模 | 不要全部承诺在本次投稿中完成 |

当前最推荐：**先完成新的平衡主测试与局部恢复图，拿到已排队history对照；如果确实还剩一次训练，就做video-loss-off。** 相比临时再接一个加速/actor模块，这组实验更能回答为什么带记忆WAM能从短纠正里受益。

若所有机制对照都无差异，主结论收缩为实际系统上的纠正学习有效性，承认尚未找到WAM特有收益来源。若两任务均改善、history或video控制有清楚差异，再强化对应方法贡献。实验应决定叙事，而不是为了既定叙事挑测试条件。
