# 三项贡献：框架、学习机制与恢复分析

## 1. 一种面向WAM的交互学习框架。

围绕精密操作中策略遇到的偏差状态，整合真机人类门控交互、保留时间上下文的纠正样本构造与原始示范回放，在已有WAM架构上实现交互后训练。

## 2. 人类校正的预测式策略自改进。

将人类动作监督、真实历史条件和未来视频自监督结合，使短纠正引导模型利用更长的人机混合经验学习纠正行为，同时保持不同监督信号的边界。

## 3. 理解视频预测如何支持错误恢复。

通过时间上下文消融，以及留出视频预测质量与实机成功率的跨checkpoint比较，研究预测与纠正行为的相互关系。圆柱任务呈现预测质量与行为表现的一致排序；适配器上，视频延伸进一步提高预测质量，却没有提高成功率，揭示预测—执行差异及这一解释的适用边界。

第三点可用标题：**视频预测如何支持错误恢复**（How Video Prediction Supports Error Recovery）。正文以问题和机制分析展开：当前是预测质量与行为改善的关联证据，不是新增视频规划器或已经证明的因果机制。

现有主结果：圆柱SFT/Segment-only/History/History+Future为7.7/30.8/38.5/46.2%，适配器为50/75/65/55%。第三项不能隐去适配器反向的消融趋势，也不能将三个checkpoint的相关性推广为普遍规律。
