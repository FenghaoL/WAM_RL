# 论文主线与三个贡献：协作写作简版

## 工作定位

**面向带记忆世界—动作模型的人类纠正后训练：利用完整交互的视觉上下文，学习短人类接管中的精密操作恢复。**

参考题目：**Learning Recovery from Human Corrections in Memory-Based World–Action Models**。

WAM（World–Action Model）将视觉预测与动作生成结合。本文使用已有AHA-WAM骨干，将其在正常示范上训练得到的任务策略，通过真实机器人接管数据进行后训练。人类主要在策略走偏后接管调正；因此本文聚焦偏差状态下的恢复，而非声称学习了一个主动故障检测器。

## 贡献一：为短人类纠正保留决策上下文

**我们建立面向带记忆WAM的纠正后训练协议，将人类动作标签的边界与历史观测的边界分开。** 接管前的真实观测用于重建当前决策所需的视觉历史，动作监督仍限定在有效人类控制区间，并与原始示范回放混合。

洞察：人类接管通常是一个局部纠正窗口，而不是任务状态的自然起点。把它裁成独立示范，会改变记忆模型看到的条件。本文通过同数据的段内历史与跨接管历史比较，检验这一构造对恢复学习的作用。

## 贡献二：在不扩展专家动作标签的前提下，利用交还后的视觉监督

**我们研究从成功混合控制轨迹延伸未来视频目标，让短纠正获得更完整的视觉预测监督，同时避免将后续自主动作直接当作专家标签。**

洞察：一个自主动作未必值得模仿，但它产生的真实视频可以作为预测学习的观测目标。本文对比段内视频与延伸视频，并在共享偏差初始化下评估恢复成功和恢复效率，另以固定输入的视频预测作诊断。

这是监督式动作学习结合自监督视觉预测；历史读取本身不是自监督损失。现有全部纠正配方均有video loss，因此该对照检验的是**未来视觉监督范围**，不是有无视频目标。是否带来恢复收益由实测决定，不预写正结论。

## 贡献三：用两个精密操作任务检验恢复能力及其保留原技能的表现

**我们在低成本SO101的圆柱插入和电源适配器插接上，建立完整任务与受控偏差恢复相结合的评估，并分析示范回放比例的影响。**

完整任务衡量实际完成能力；共享偏差起点衡量面对相同错误时的恢复能力；阶段完成时间和重试次数区分有效纠偏与无效动作。1:1和2:1作为训练配方的敏感性对照，不作为新采样算法。视频预测分析用于解释视觉与动作表现，不将生成视频等同于动作条件模拟器。

## 三点如何连成一篇论文

**短纠正缺少前文 → 保留跨接管历史；短纠正缺少完整未来目标 → 延伸视觉监督；观察到纠偏不等于恢复完成 → 在共享错误状态下量化恢复。**

推荐正文顺序：问题与骨干 → 人类动作/历史/未来三种时间范围 → 联合训练与demo回放 → 两任务完整成功率 → 历史与视频范围对照 → 恢复范围/效率 → 视频诊断与局限。

## 已有证据与写作边界

- 共同13个初始化的首次rollout：cylinder SFT为1/13，跨接管历史＋段内视频为5/13，跨接管历史＋未来视频延伸为6/13。后两者只差一次成功，尚不能据此主张延伸明确更优。
- 八个纠正checkpoint是两个任务各四个设置；另保留两个任务SFT作参照。训练完成与对应实机结果分别登记。
- “不带历史”在本轮指纠正样本的历史不跨接管边界，**不是整个骨干关闭memory**。
- 两任务段内历史配置并非逐参数一致；power还改变了历史采样规则，作为历史构造整体对照，不能归因于单个开关。
- 当前核对的2:1配置有video loss，但没有未来延伸，须与1:1段内视频版本比较。
- 数据主要覆盖错误后的调正，支持以恢复为研究重点；但仅从数据来源不能断言模型完全没有学到避免错误。该区分由完整任务和局部恢复测试共同判断。
- 不主张新RL、新WAM骨干、WAM普遍优于VLA、机械漂移已被解决，或1:1为首创。若历史/延伸对照无差异，保留方法设计与实证边界，不宣称每项设计均贡献性能。
